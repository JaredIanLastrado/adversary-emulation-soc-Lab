# Microsoft Sentinel

Microsoft Sentinel extends AESOC into cloud-native SIEM monitoring using Azure Activity logs, KQL analytics rules, automated alerting, and incident management.

## Environment

- Microsoft Sentinel
- Log Analytics workspace: `law-aesoc-sentinel`
- Azure Activity connector
- Microsoft Defender portal
- Kusto Query Language (KQL)
